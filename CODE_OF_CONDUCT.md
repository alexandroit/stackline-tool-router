# Code of Conduct

## Our standard

Project spaces should be professional, constructive, and welcoming. Discuss
observable behavior, evidence, compatibility, and tradeoffs. Harassment,
personal attacks, discrimination, and disclosure of private information are
not accepted.

## Scope

This standard applies to repository discussions, issues, pull requests,
reviews, and other project-managed spaces.

## Enforcement

Maintainers may edit, remove, or reject contributions and participation that
violate this standard. Serious or repeated violations may result in a ban.
Security reports must use the private process described in SECURITY.md.
